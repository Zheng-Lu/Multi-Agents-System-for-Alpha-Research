# Controlled comparison increment

2026-11-04. Extend the existing three-pattern lab before implementing persistent collaboration.

- Keep historical demonstrations replayable; controlled presets carry an explicit case/version.
- Compare one fixed candidate workload, tool permissions, model assignment and aggregate budget.
  A team does not receive a larger run allowance just because it has more agents.
- Report peak input tokens per invocation per agent, not a cumulative context-size claim.
  Mock tokens are estimates. Missing provider usage stays unknown.
- Separate model proposals, model review decisions, deterministic grading and publication.
  The same publication gate blocks invalid or unverified recommendations in every architecture.
- Add a timestamped earnings-revision challenge. Diagnostic tools provide evidence; the grader's
  verdict is not a reviewing model's answer. Demo decisions are explicitly scripted mechanics,
  never evidence of typical model failure or verifier superiority.
- Include a single-context parallel-tool control before attributing speed to multiple agents.
  Optional mock delay illustrates concurrency only; zero-delay comparisons remain available.
- Use a small persisted comparison group/scorecard, not a general benchmark framework.
  Any future live campaign needs its own spending authorization and retains every attempt.

These are lab experiment choices. The official [Anthropic definitions](https://claude.com/resources/articles/multi-agent-coordination-patterns)
remain generator/independent verifier with bounded feedback and lead/scoped temporary subagents.
Do not add a guaranteed baseline failure or a fixed multi-agent winner.
